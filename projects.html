Predictive Maintenance for Industrial Equipment

Dataset Type: Simulated sensor and operational data representing equipment degradation patterns.

Problem Formulation: Failure prediction under limited labeled fault data in industrial systems.

Methodology: Feature engineering from simulated sensor variables followed by supervised learning using Logistic Regression, chosen for interpretability and baseline reliability.

Evaluation Metric: Precision–Recall, appropriate for class-imbalanced failure prediction.

Limitation: Model performance depends on assumptions in the simulated data; real-world deployment would require validation on operational sensor datasets.

Anomaly Detection in Financial Transactions

Dataset Type: Synthetic financial transaction data with severe class imbalance.

Problem Formulation: Identification of rare fraudulent transactions in highly imbalanced datasets.

Methodology: Classification-based anomaly detection with evaluation focused on imbalance-aware metrics rather than accuracy.

Key Technical Insight: Accuracy is misleading in fraud detection; precision–recall analysis provides a more reliable assessment of model usefulness under extreme imbalance.

Limitation: Synthetic data may not capture evolving real-world fraud behavior and noise patterns.

Data-Driven Modeling of Gallium-Based System Behavior

Nature: Ongoing independent research project

Objective: To davelop a data-driven machine learning model that predicts and optimizes electrical energy output from gallium phase-change cycles using real-time thermal and electrical data.

Research Basis: This research is grounded in time-series data analysis and machine learning applied to phase-change thermal system,transforming physical heat transitions into predictable and optimizable data patterns.

Core Challenges: Modeling noisy, low-power thermal-electrical time-series data and designing ultra-lightweight ML Algorithms that improve efficiency without exceeding the system's energy budget
